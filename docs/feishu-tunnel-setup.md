# 飞书内网穿透配置指南

## 问题分析
飞书平台在公网上，无法直接访问您的局域网服务器 (192.168.43.250:5000)
需要使用内网穿透工具让飞书能够访问到您的Webhook服务器。

## 解决方案

### 方案1: 使用ngrok（推荐）

#### 1. 下载ngrok
访问 https://ngrok.com/download 下载适合您系统的版本

#### 2. 启动ngrok
```bash
# 解压后，在命令行中运行
ngrok http 5000
```

#### 3. 获取公网URL
ngrok会显示类似这样的信息：
```
Forwarding  https://abc123.ngrok.io -> http://localhost:5000
```

#### 4. 配置飞书
在飞书开发者后台的**事件订阅**页面，设置请求地址为：
```
https://abc123.ngrok.io/webhook/feishu
```
（替换为您的实际ngrok URL）

### 方案2: 使用其他内网穿透工具

#### frp（免费开源）
1. 下载frp客户端
2. 配置frp.ini文件
3. 启动frp客户端

#### 花生壳（国内服务）
1. 注册花生壳账号
2. 下载花生壳客户端
3. 配置内网映射

#### localtunnel（简单易用）
```bash
npm install -g localtunnel
lt --port 5000
```

## 测试步骤

1. 启动内网穿透工具
2. 复制生成的公网URL
3. 在飞书开发者后台更新事件订阅URL
4. 等待飞书验证URL
5. 从飞书客户端发送测试消息

## 注意事项

1. **免费版限制**：ngrok免费版每次重启URL会变化，需要重新配置
2. **稳定性**：免费内网穿透可能不稳定，建议生产环境使用付费服务
3. **安全性**：公网URL可能被其他人访问，注意安全配置

## 验证配置

配置完成后，可以通过以下方式验证：

1. 检查ngrok日志，确认收到飞书请求
2. 查看Webhook服务器日志，确认处理飞书事件
3. 从飞书客户端发送消息，确认收到回复
