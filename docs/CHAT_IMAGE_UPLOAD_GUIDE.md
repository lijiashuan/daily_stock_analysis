# Chat 页面图片识别功能

## 功能说明

在 `/chat` 页面新增了**图片导入功能**，允许用户上传股票相关的截图（如 K 线图、技术指标截图、自选股列表等），由 AI 自动识别图中的股票信息并进行分析。

## 使用方法

### 1. 上传图片

1. 打开浏览器访问 `http://127.0.0.1:8000/chat`
2. 在输入框左侧找到 **图片上传按钮**（图片图标）
3. 点击按钮选择要上传的图片文件

### 2. 图片预览

- 选中图片后会自动显示预览缩略图（最大高度 128px）
- 点击预览图右上角的 **×** 按钮可移除图片

### 3. 发送分析

- 在文本框中输入您的问题（可选）
- 点击 **发送** 按钮
- 系统会自动：
  1. 识别图片中的股票代码和名称
  2. 将识别结果附加到您的问题上
  3. 调用 AI 分析这些股票

## 支持的图片格式

- **JPEG/JPG**
- **PNG**
- **WebP**
- **GIF**

**最大文件大小**: 5MB

## 示例场景

### 场景 1: 自选股列表截图
1. 截图您的自选股列表
2. 上传到 Chat 页面
3. 输入问题："帮我分析这些股票的技术面"
4. AI 会识别所有股票并逐个分析

### 场景 2: K 线图截图
1. 截图某只股票的 K 线图
2. 上传并询问："这只股票现在能买吗？"
3. AI 会识别股票代码并分析其走势

### 场景 3: 技术指标截图
1. 截图包含 MACD、KDJ 等技术指标的界面
2. 上传并询问："帮我解读这些技术指标"
3. AI 会识别股票并分析指标含义

## 技术实现

### 后端
- **API 端点**: `/api/v1/agent/chat/stream`
- **图片处理**: `src/services/image_stock_extractor.py`
- **Vision LLM**: 支持 Gemini/Anthropic/OpenAI 多模型

### 前端
- **状态管理**: `selectedImage`, `imagePreview`, `imageData`
- **消息显示**: 用户消息支持显示图片缩略图
- **API 调用**: Base64 编码传输图片数据

## 识别效果

图片识别的准确度取决于：
1. 图片清晰度
2. 文字是否完整
3. 股票代码是否清晰可见

如果识别失败，系统会在问题前添加提示信息，AI 仍会尝试根据您的文字问题进行回答。

## 注意事项

- 图片识别需要消耗 Vision API 的 tokens
- 确保已配置 LLM API Key（GEMINI_API_KEYS / ANTHROPIC_API_KEYS / OPENAI_API_KEYS）
- 识别结果会显示在 SSE 流中（`image_recognized` 事件）
