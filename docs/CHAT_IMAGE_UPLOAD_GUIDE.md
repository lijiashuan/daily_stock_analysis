# Chat 页面图片识别功能

## 功能说明

在 `/chat` 页面新增了**图片导入功能**，允许用户上传股票相关的截图（如 K 线图、技术指标截图、自选股列表等），由 AI 自动识别图中的股票信息并进行分析。

## 配置方法

### 1. 获取百度智能云 API Key

1. 访问 [百度智能云控制台](https://console.bce.baidu.com/ai/)
2. 注册/登录账号
3. 创建应用，开通**通用文字识别**服务
4. 获取 `App ID`、`API Key`、`Secret Key`

### 2. 配置环境变量

在 `.env` 文件中添加以下配置：

```bash
# 百度智能云 OCR 配置
BAIDU_OCR_APP_ID=你的AppID
BAIDU_OCR_API_KEY=你的APIKey
BAIDU_OCR_SECRET_KEY=你的SecretKey
```

### 3. 安装依赖

```bash
pip install baidu-aip
```

### 4. 重启服务

```bash
python main.py --webui-only
```

## 使用方法

### 1. 上传图片

1. 打开浏览器访问 `http://127.0.0.1:8000/chat`
2. 在输入框左侧找到 **图片上传按钮**（图片图标）
3. 点击按钮选择要上传的图片文件

### 2. 图片预览

- 选中图片后会自动显示预览缩略图（最大高度 128px）
- 点击预览图右上角的 **×** 按钮可移除图片

### 3. 发送分析

- 在文本框中输入您的问题（可选）
- 点击 **发送** 按钮
- 系统会自动：
  1. 识别图片中的股票代码和名称
  2. 将识别结果附加到您的问题上
  3. 调用 AI 分析这些股票

## 支持的图片格式

- **JPEG/JPG**
- **PNG**
- **WebP**
- **GIF**

**最大文件大小**: 5MB

## 示例场景

### 场景 1: 自选股列表截图
1. 截图您的自选股列表
2. 上传到 Chat 页面
3. 输入问题："帮我分析这些股票的技术面"
4. AI 会识别所有股票并逐个分析

### 场景 2: K 线图截图
1. 截图某只股票的 K 线图
2. 上传并询问："这只股票现在能买吗？"
3. AI 会识别股票代码并分析其走势

### 场景 3: 技术指标截图
1. 截图包含 MACD、KDJ 等技术指标的界面
2. 上传并询问："帮我解读这些技术指标"
3. AI 会识别股票并分析指标含义

## 技术实现

### 后端
- **API 端点**: `/api/v1/agent/chat/stream`
- **图片处理**: `src/services/image_stock_extractor.py`
- **OCR 引擎**: 百度智能云 OCR（通用文字识别高精度版）
- **SDK**: baidu-aip

### 前端
- **组件**: `apps/dsa-web/src/pages/ChatPage.tsx`
- **文件上传**: HTML5 File API
- **预览**: Base64 Data URL

## 优势

使用百度智能云 OCR 的优势：
- ✅ **速度快**：OCR 识别通常比 Vision LLM 快 3-5 倍
- ✅ **成本低**：每天 500 次免费额度，超出后也非常便宜
- ✅ **准确率高**：专门优化的中文识别引擎
- ✅ **稳定性好**：国内服务，无网络延迟
- ✅ **支持离线**：可下载离线 SDK（需购买授权）

## 识别效果

图片识别的准确度取决于：
1. 图片清晰度
2. 文字是否完整
3. 股票代码是否清晰可见

如果识别失败，系统会在问题前添加提示信息，AI 仍会尝试根据您的文字问题进行回答。

## 注意事项

- 图片识别需要消耗百度智能云 OCR 的调用次数（每天 500 次免费）
- 确保已正确配置 BAIDU_OCR_APP_ID、BAIDU_OCR_API_KEY、BAIDU_OCR_SECRET_KEY
- 识别结果会显示在 SSE 流中（`image_recognized` 事件）
- 支持图片格式：JPEG、PNG、WebP、GIF
- 最大文件大小：5MB
